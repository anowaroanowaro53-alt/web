# صفحة هبوط "ركن الصلاة الخشبي الملكي" (Royal Prayer Corner Landing Page)

صفحة هبوط تفاعلية متكاملة وفاخرة لمنتج "ركن الصلاة الخشبي الملكي"، مصممة بلغة HTML5 و Tailwind CSS و JavaScript مع دمج سلس داخل تطبيق أندرويد عبر WebView متقدم، لتوفر تجربة تسوق روحانية واستعراضاً دقيقاً للمنتج مع نظام حساب تكاليف الشحن حسب الولايات وتأكيد الطلب عبر واتساب.

---

### User Review & Critical Decisions

> [!IMPORTANT]
> تم تأكيد الخيارات الرئيسية التالية وفق إجاباتك في المرحلة الأولى:
> - **طريقة العرض**: صفحة ويب متكاملة ومتحركة (HTML5 + Tailwind CSS + JS) تعمل بكفاءة عالية داخل WebView في تطبيق أندرويد، مع توفير خيار نسخ الكود المصدري الكامل.
> - **سلوك تأكيد الطلب**: إظهار نافذة تأكيد إسلامية ملكية تفاعلية تتضمن ملخص الفاتورة ورقم الطلب، مع زر مباشر لإرسال تفاصيل الطلب بنقرة واحدة عبر WhatsApp.
> - **تخصيص نموذج الطلب**: إضافة محدد كمية تفاعلي وحاسبة تلقائية لتكلفة التوصيل ومجموع الطلب وفق الولاية المختارة (من بين الـ 58 ولاية).

---

## 1. نظرة عامة وفكرة المشروع (Overview & Core Concept)

- **ماهية المنتج**: ركن صلاة خشبي منجد بنقوش أركت إسلامية راقية وخشب MDF ناصع البياض، يدمج رفاً للمصحف، ورفاً للمبخرة والسبحة، وحجيرة سفلية واسعة لسجادات ومصليات الصلاة.
- **الجمهور المستهدف**: العائلات والمنازل الراغبة في تخصيص ركن عبادة مريح وفاخر، وهدايا المقبلين على الزواج والمناسبات الدينية.
- **القيمة المضافة**: تحويل زاوية المنزل إلى واحة من السكينة عبر تجربة رقمية تفاعلية تعكس روحانية وفخامة المنتج مع سهولة الطلب بنظام الدفع عند الاستلام.

---

## 2. تجربة المستخدم والتصميم البصري (User Experience & Visual Design)

### رحلة المستخدم (User Journey)
1. **الوصول والترحيب**: يفتح التطبيق مباشرة على شاشة الركن الملكي مع شريط علوي أنيق (Header) يتضمن شعار "محراب الفخامة" وزر اتخاذ إجراء فوري (اطلب الآن).
2. **قسم البطل (Hero Section)**: عنوان ملهم ("حوّل صلاتك لواحة من الراحة والسكينة")، عرض صورة المنتج مع هالة ذهبية ناعمة (Glow Effect)، وشارة السعر الجريئة (4500 دج) مع شارة خصم وتوصيل.
3. **شبكة الميزات (Features Grid)**: 5 بطاقات تفاعلية بتأثيرات Hover/Touch راقية:
   - 📖 رف علوي مائل مريح لقراءة المصحف الشريف.
   - 📿 رف أوسط للمبخرة ونشر عبق العود والعطور.
   - 🕋 خزانة سفلية رحبة لسجادات الصلاة وملحقاتها.
   - 🎨 خشب MDF ناصع البياض بنقوش إسلامية أركت دقيقة.
   - 📏 الأبعاد: الارتفاع 1.17 م | العرض 40 سم | العمق 35 سم.
4. **معرض الصور التفاعلي (Responsive Carousel)**: استعراض تفاصيل المنتج وزواياه المختلفة مع أزرار تنقل ونقاط مؤشر (Dots) وتكبير تفاعلي.
5. **نموذج الطلب الذكي (Smart Order Form)**:
   - الاسم الكامل ورقم الهاتف.
   - قائمة الولايات الـ 58 الجزائرية مع احتساب سعر التوصيل التلقائي.
   - محدد الكمية (+ / -) وحساب الإجمالي الفوري.
   - زر بارز: "تأكيد الطلب - الدفع عند الاستلام".
6. **نافذة التأكيد وإرسال واتساب (Confirmation Modal & WhatsApp)**: عرض بطاقة الطلب الذهبية وزر نقل البيانات إلى واتساب لإتمام المعاملة فوراً.
7. **التذييل وشارات الثقة (Footer & Trust Badges)**: ضمان المعاينة قبل الدفع، سرعة الشحن، وخدمة العملاء.

### الهوية البصرية ولوحة الألوان
- **الاتجاه**: RTL كامل باللغة العربية.
- **الخطوط**: خط `Cairo` / `Tajawal` العربي الراقي من Google Fonts.
- **الألوان الأساسية**:
  - خلفية ناصعة وبيضاء عاجية: `#FCFBF7` و `#FFFFFF`.
  - الذهبي الملكي الفاخر: `#D4AF37` وتدرجاته (`#B8860B`, `#F3E5AB`).
  - البيج الدافئ الهادئ: `#F5EFEB`.
  - النص الأساسي: لون فحمي فاخر مريح للقراءة `#1F2421`.
- **التأثيرات الحركية (Micro-Interactions)**:
  - تدرج لوني متحرك في الخلفية (Subtle Golden Aura Animation).
  - انتقال سلس (Smooth Transitions) وتكبير طفيف عند التمرير على البطاقات والأزرار.
  - مؤشر تمرير مرن وشريط تنقل مثبت.

## 3. القرارات التقنية وحلول التصميم (Technical Architecture & Product Decisions)

### القرارات التقنية الرئيسية
1. **هندسة العرض (Android + HTML5/Tailwind/JS)**:
   - بناء صفحة الويب بنظام أحادي المصدر (Single-File Autonomous Asset) في `assets/index.html` مع تضمين Tailwind CSS و Google Fonts و Feather/Lucide Icons و FontAwesome بدون أي اعتماد خارجي يعيق العمل بدون إنترنت.
   - تشغيل الصفحة داخل `Android WebView` سريع ومعد بأفضل إعدادات الأداء، دعم JavaScript، وواجهة Android Interface لفتح تطبيق WhatsApp مباشرة.
   - إضافة شريط أدوات Compose علوي أنيق يحتوي على زر "نسخ كود الـ HTML" وزر "مشاركة الرابط" لتسهيل استخدام الكود خارج التطبيق.
2. **محرك حساب تكلفة الشحن**:
   - تضمين مصفوفة كاملة للولايات الجزائرية مع متوسط تسعيرة الشحن لكل منطقة (شمال، هضاب، جنوب).
   - تحديث السعر الإجمالي لحظياً فور تغيير الولاية أو الكمية.

### خطة الإنجاز خطوة بخطوة:
1. تحديث `metadata.json` و `strings.xml` لتسمية التطبيق بـ "ركن الصلاة الملكي".
2. تصميم وبناء ملف `assets/index.html` الكامل متضمناً هيكلية HTML5، تنسيقات Tailwind CSS، تأثيرات الـ Glow والتحريك، خط Cairo، معرض الصور التفاعلي، ونظام الطلب الذكي.
3. تجهيز `MainActivity.kt` بـ WebView مهيأ ومحمي مع واجهة تفاعلية تربط إرسال الطلب بتطبيق WhatsApp وميزة نسخ كود HTML للمستخدم.
4. التحقق والترجمة عبر `compile_applet`.
